# LIYU GEBEYA Backend

Backend services for the LIYU GEBEYA marketplace in Ethiopia.

## Main Features

- User Registration and Login
- User Profiles
- Advertisement Management
- Category Management
- Image Upload (Maximum 5 Photos)
- Search and Filtering
- Seller Management
- Favorites
- Messaging

## Technology

- Backend API
- PostgreSQL Database
- AletCloud Hosting
- Secure HTTPS Communication

LIYU GEBEYA Marketplace
